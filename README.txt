# Ganpati Invitation Website

Open `index.html` in a browser.

## Personalize
Edit `index.html` to change:
- Host/family name
- Date and time
- Address
- Google Maps link
- WhatsApp RSVP message

Edit `script.js` to change the countdown target date.

Optional: add an MP3 named `ganpati-music.mp3` in this folder for the music button.

For publishing, upload the folder to GitHub Pages, Netlify, Vercel, or another static hosting service.
